03 / Release signal

First touch.Before credentials.

Version 1.5.0 opens a first-touch Active Directory assessment path: discover in-scope DCs, fingerprint web surfaces, and map anonymous SMB posture before credentials are available. It also adds a supported-coercion-family matrix and hashcat-mode guidance on roast output.

0 credentialsScoped DNS discovery · web fingerprint · SMB posture
One null sessionPer-host anonymous SMB / RPC posture in deep runs
SHA-256 + SigstoreVerification material and instructions are available
Truth boundary

The validation ledger remains authoritative for support and readiness claims. Version 1.5.0 identifies scoped, observable AD surfaces; a reachable endpoint or response is evidence to inspect, not proof of exploitability.

Published / 2026-09-04

GitHub Releases and crates.io now offer 1.5.0. Static release builds use rustls with bundled AWS-LC; each platform build has a SHA-256 sidecar and GitHub OIDC Sigstore attestation instructions.

ADhammer composes published standalone icedracon crates into one Rust engine. Each layer remains independently inspectable and reusable outside the binary.
