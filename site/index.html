05 / Protocol universe

Built from the wire up.

ADhammer composes published standalone icedracon crates into one Rust engine. Each layer remains independently inspectable and reusable outside the binary.

Layer / DirectoryLDAP + security descriptors

Collection, controls, ACL interpretation, and typed directory objects.

Layer / RPCDCE/RPC

MS-DRSR, MS-NRPC, MS-SAMR, MS-RRP, and other Microsoft interfaces.

Layer / IdentityKerberos

PAC, FAST, PKINIT, ticket material, and ccache / kirbi codecs.

Layer / AuthNTLM + CredSSP

Authentication and crypto primitives composed without shell-wrapper glue.

Layer / TransportSMB2 + NDR

Transport, marshalling, reassembly, and Windows protocol structure.

Layer / OutputBloodHound export

Graph-compatible data while finding and evidence context remains intact.
